Pair of Linear Equations

Complete Class 10 CBSE Notes • NCERT Based • Board Exam Revision

Introduction

A pair of linear equations in two variables consists of two equations having the same two variables. The values of x and y that satisfy both equations are called the solution.

ax + by + c = 0

where

  • a and b are coefficients
  • c is constant
  • a and b cannot both be zero

Example

2x + y = 7

3x - y = 8

These two equations together form a Pair of Linear Equations.

Methods of Solving

1. Graphical Method

Draw both equations on graph paper. The point where they intersect is the solution.

2. Substitution Method

Find one variable from one equation and substitute into the other.

3. Elimination Method

Eliminate one variable by adding or subtracting equations.

4. Cross Multiplication

Direct method using determinants. Mostly used in board exams.

Graphical Method

Draw both equations on graph paper. Observe the lines carefully.

Type of Lines Number of Solutions
Intersecting One Unique Solution
Parallel No Solution
Coincident Infinite Solutions

Substitution Method

Steps

  1. Find one variable from any equation.
  2. Substitute it into the second equation.
  3. Find the remaining variable.
  4. Substitute back.

Example

x + y = 7

x − y = 3

From first equation

x = 7 − y

Substitute into second equation.

(7 − y) − y = 3
7 − 2y = 3
y = 2
x = 5
Answer = (5 , 2)

Elimination Method

Steps

  1. Make coefficients equal.
  2. Add or subtract equations.
  3. Find one variable.
  4. Substitute back.

Example

2x + y = 9

2x − y = 3

Add both equations

4x = 12
x = 3
y = 3
Answer = (3 , 3)

Cross Multiplication Method

This method is useful for solving equations directly and is commonly used in CBSE Board examinations.

a₁x + b₁y + c₁ = 0

a₂x + b₂y + c₂ = 0

Formula

x / (b₁c₂ − b₂c₁)
=
y / (c₁a₂ − c₂a₁)
=
1 / (a₁b₂ − a₂b₁)

Consistency of Pair of Equations

Condition Result
a₁/a₂ ≠ b₁/b₂ One Unique Solution
a₁/a₂ = b₁/b₂ ≠ c₁/c₂ No Solution
a₁/a₂ = b₁/b₂ = c₁/c₂ Infinite Solutions

Important Formula

a₁x + b₁y + c₁ = 0

a₂x + b₂y + c₂ = 0
  • Unique Solution : a₁/a₂ ≠ b₁/b₂
  • No Solution : a₁/a₂ = b₁/b₂ ≠ c₁/c₂
  • Infinite Solutions : a₁/a₂ = b₁/b₂ = c₁/c₂
