Polynomials

Quick Revision Notes • 8 min read

📘 What is a Polynomial?

A polynomial is an algebraic expression made up of variables and constants having whole number exponents only.

Examples ✔
  • x + 5
  • 3x² − 4x + 7
  • 5y³ + 2y − 1

Not Polynomials ✘
  • 1/x
  • √x
  • x⁻²

📏 Degree of a Polynomial

The highest power of the variable is called the degree of the polynomial.

Polynomial Degree
7 0
x + 4 1
2x² + 5x + 1 2
x³ − 2x² + x 3
5x⁴ + 3 4

📚 Types of Polynomials

Degree Name
0 Constant Polynomial
1 Linear Polynomial
2 Quadratic Polynomial
3 Cubic Polynomial

Examples

  • Constant → 8
  • Linear → 3x + 2
  • Quadratic → x² + 4x + 5
  • Cubic → x³ − 5x + 2

🎯 Zeroes (Roots) of a Polynomial

A zero is the value of x that makes the polynomial equal to zero.

Example

p(x) = x − 3

Put x = 3
3 − 3 = 0

Zero = 3

📝 Example

Find the zero of 2x + 6

2x + 6 = 0
2x = −6
x = −3

Zero = −3

📈 Geometrical Meaning of Zeroes

The zeroes of a polynomial are the points where its graph cuts or touches the x-axis.

Maximum Number of Zeroes
  • Linear Polynomial → 1
  • Quadratic Polynomial → 2
  • Cubic Polynomial → 3

🔗 Relationship Between Zeroes & Coefficients

(A) Linear Polynomial

ax + b

Zero = −b / a

(B) Quadratic Polynomial

ax² + bx + c

α + β = −b / a

αβ = c / a

🧮 Example

Polynomial:

x² − 5x + 6

a = 1
b = −5
c = 6

Sum of Zeroes = 5
Product of Zeroes = 6

Zeroes = 2 and 3

✔ 2 + 3 = 5
✔ 2 × 3 = 6

📝 Forming a Quadratic Polynomial

If the zeroes are α and β, then the polynomial is

x² − (α + β)x + αβ
Example

Zeroes = 4 and 5
Sum = 9
Product = 20

Polynomial
x² − 9x + 20

📚 Division Algorithm

Every polynomial satisfies the Division Algorithm.

Dividend = Divisor × Quotient + Remainder
p(x) = g(x) × q(x) + r(x)

p(x) → Dividend
g(x) → Divisor
q(x) → Quotient
r(x) → Remainder

📝 Division Example

Divide

x² + 5x + 6
by
x + 2

Quotient = x + 3
Remainder = 0

⭐ Formula Box

α + β = −b/a

αβ = c/a

x² − (α + β)x + αβ

Dividend = Divisor × Quotient + Remainder

📌 Important NCERT Points

  • ✔ Degree = Highest power of the variable.
  • ✔ Polynomial can have one or more terms.
  • ✔ Zeroes make the polynomial equal to zero.
  • ✔ Graph cuts or touches the x-axis at zeroes.
  • ✔ Quadratic polynomial has at most two zeroes.
  • ✔ Learn the sum & product formulas.
  • ✔ Practice Division Algorithm questions.
